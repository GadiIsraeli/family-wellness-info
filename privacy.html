Privacy policy

Last updated: September 21, 2026. This notice covers the private Family Wellness Monitor application and this informational website.

Current version

The current local application does not connect to Oura, collect Oura measurements or send Telegram notifications. It creates a local SQLite database for synchronization status. Its server records operational events and may record request metadata in access logs.

Planned collection and purpose

Once implemented and authorized by the account holder, the application will request heart-rate data, daily sleep/readiness/activity information and available overnight SpO2 data. It will store measurement times, synchronization status and wellness check-in alerts to support private family viewing and data-freshness monitoring.

OAuth access and refresh tokens will be stored locally to maintain the authorized connection. The application will not ask for the account holder’s Oura password. Account identification will be used only if available through the permissions actually granted.

Storage and access

The operator will keep measurements and credentials on their own computer, with access limited to the operator and family members authorized by the account holder. SQLite is not encrypted by the application. Device protection and any backup protection are the operator’s responsibility. Health information will not be placed in this public website or its repository.

Sharing and optional notifications

The project does not sell data or use it for advertising. Oura processes ring data under its own policies. If Telegram notifications are implemented and enabled with the account holder’s agreement, alert text, potentially including health values and timestamps, will be sent through Telegram to the configured recipient. Telegram has its own data-handling policies; those notifications will no longer be confined to the local computer.

Retention, disconnection and deletion

Once collection is available, historical records will remain until the operator deletes them; automatic expiry is not currently provided. The account holder may ask the operator to stop collection or delete local records, credentials and operator-controlled backups. Revoking access in Oura stops future authorized access but does not delete records already collected. Copies in Telegram and independently retained backups require separate deletion.

This public website

These static pages include no analytics scripts, advertising, forms or application cookies. When hosted on GitHub Pages, GitHub receives technical request information such as IP addresses under its privacy statement. No Oura data is needed to view these pages.
