Family Wellness Monitor

A private, self-hosted family wellness project using Oura data with the account holder’s permission.

What it is for

The planned application lets an authorized family member review recent heart rate, sleep, readiness, activity and available overnight SpO2 measurements. It will make data freshness prominent and offer optional check-in reminders.

Development status

The current version is a local dashboard and database foundation. Oura account connection, data collection and notifications are not enabled yet. These pages describe the current version and clearly label planned features.

Private by design

This public website contains project information only. It does not host the wellness dashboard, account credentials or measurements. The dashboard runs on the operator’s own computer.

Limitations

This is not a medical device or emergency monitoring service. Oura data may be delayed or unavailable. A future check-in reminder would not be a diagnosis, and the absence of an alert would not establish that someone is well.

This is an independent project, not an official Oura application or an endorsement by Oura.
